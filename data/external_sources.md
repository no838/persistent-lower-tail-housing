# External public source links

This repository includes compact analysis-ready research tables. It does not
redistribute large public raw datasets that already have official release pages.
The public source datasets used by the manuscript can be accessed from the
following sources.

## UK transaction records

HM Land Registry Price Paid Data.

- Official collection: https://www.gov.uk/government/collections/price-paid-data
- Download page: https://www.gov.uk/government/statistical-data-sets/price-paid-data-downloads

The manuscript uses HM Land Registry price-paid records as the public UK
transaction source for city-frame holdout replication.

## France DVF transaction records

Demandes de valeurs foncières (DVF), data.gouv.fr.

- Official dataset page: https://www.data.gouv.fr/datasets/demandes-de-valeurs-foncieres/

The manuscript uses the official 2021-2025 rolling-window DVF raw files to build
department-frame extension tables.

## SinoBF-1 building-function data

SinoBF-1 building-function dataset.

- Zenodo record: https://zenodo.org/records/17844789

The manuscript uses SinoBF-1 as a functional-morphology sidecar for
phase-conditioned drift diagnostics.

## China building-height data

China building-height dataset associated with the Scientific Data descriptor:
"A building height dataset across China in 2017 estimated by the
spatially-informed approach".

- Article page: https://www.nature.com/articles/s41597-022-01192-x
- Data DOI: https://doi.org/10.6084/m9.figshare.14999067.v2

The manuscript uses this dataset as a Chinese urban morphology reference layer.

## ChinaUV settlement-morphology data

ChinaUV++ urban-village, roof and population products.

- ScienceDB DOI: https://doi.org/10.57760/sciencedb.28387

The manuscript uses the urban-village polygons, roof layer and population raster
as settlement-morphology sidecars. The repository includes only derived
manuscript-level summaries, not the full geospatial source products.
